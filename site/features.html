FEATURES

Less hunting.
More clarity.

A local view of your CLI installations, running sessions, and supported updates. Know what you have before deciding what to change.

01 / DISCOVER

Your tools, in one inventory.

Manage OmO, Pi, OMP, OpenCode, Claude Code, Codex and GJC. See discovered paths and disk versions, review the installation plan, then sign in separately when your tool requires it.

Other herdr sessions remain visible in Terminal sessions, marked not yet supported and without update or restart controls. A discovered installation alone does not grant update authority.

Explore the CLI catalog →
02 / OBSERVE

See what is actually running.

Inspect supported CLI processes, terminal IDs, and start times. Matching executable paths connect sessions to installations. Processes bundled with another app remain separate.

A disk version is not proof of a running process’s version. Unrecorded launch versions stay unknown. External sessions are observation-only.

03 / REVIEW

A next step, not a guessing game.

The dashboard shows confirmed updates, open work, and active sessions. Prepare a supported update, review its target and impact, then explicitly confirm execution.

Verified installation times are recorded separately from session restarts. Original-installation updates currently target supported macOS Bun-global OmO installations.

04 / AUTOMATE

Choose what happens while you are away.

Keep automation off, check for updates, or enable supported updates and managed-session restarts. Choose the first check and interval per installation.

Automation starts off. Existing external terminals are never treated as sessions this app can stop or restart. The local service must stay running.
