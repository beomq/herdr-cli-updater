### Revised safety and transaction decisions
- update-only는 절대 pane exit/restart 없음. 정확한 installer digest+resource write-set busy-safe proof가 있을 때만 live consumers와 update. 나머지는 work idle가 아니라 resource를 쓰는 process 종료까지 기다리거나 blocked. update-and-restart는 모든 affected consumer의 drain+input claim→graceful exit→update→verify→선택 targets resume. 비선택 consumer는 자동 종료하지 않으며 live-safe 없으면 사용자가 직접 종료할 때까지 막는다.
- install transaction: queued/waiting_resources/updating/verifying/succeeded/failed/recovery_required. target transaction: waiting_completion/claimed/stopping/exited/launching/verifying/completed/recovery_required/cancelled. install+모든 선택 target 성공일 때만 job completed. 부분 성공은 partial/recovery다.
- Proposed core API namespace `updater.restart.inspect/claim/stop/start/result/release`는 현재 RPC가 아니다. binding은 server epoch,pane generation,root process incarnation(realpath+start identity),session,cwd,argv/options,turn generation. owner token+operationId+expected binding을 compare-and-execute하고 side effect 이전 durable intent와 queryable receipt를 제공한다.
- 입력은 native terminal attach/client, pane send_text/send_keys/send_input/input.set, agent.prompt/send_keys, 웹 raw HTTP/ws/composer queue 모두 core admission에서 봉쇄한다. claim 전 입력은 work/drain에 포함, claim 후 sequence durable queue. CLI consume ack가 verified일 때만 replay. unknown ack면 recovery_required, 중복 전송 금지.
- 사용자별 global 단일 install mutation queue. canonical resource overlap을 보관하지만 generic lock graph/병렬 updater는 만들지 않는다. requestId/jobId dedup. native self-update/외부 manager는 lock 밖이므로 fingerprint conflict를 드러내고 작업을 중지한다. 전체 consumers/write-set 모르면 busy-safe=false.
- Unknown core/source/adapter는 disabled(reason) 개발 gate이며 전체 지원 완료로 계산하지 않는다. 최종 제품은 adapter8/8와 모든 IS 실제 QA PASS가 필요하다.
- endpoint: 0700 user-private directory, 0600 Unix socket/SQLite/capability-token file, random local capability token 인증과 version/requestId. token은 log/argv/history에 쓰지 않는다. Same-UID는 trusted; 미확인 Bun peerUID 강제 가정 제거. 다른 UID는 directory/socket OS permissions로 막으며 disposable cross-UID macOS CI helper가 실제 접근 거부를 증명해야 한다.
- core public pinned ref와 installed version/schema digest를 확인하고 modified core는 isolated prefix에 build한다. 운영 herdr 교체/배포는 별도 승인. feature handshake version/digest mismatch면 restart disabled.
- agy는 Google native terminal CLI. docs flags와 shipped installer 불일치: script --dir만, latest manifest/checksum/cp/install+background self-update. immutable fetched source digest/parser/write-set와 isolated result binary를 검증하기 전 update enable 금지. docs의 --skip-aliases/--skip-path는 fetched shell parser에 없으므로 source 검증 없이 전달 금지.
- OmO wrapper+own pinned Senpi engine는 하나의 owned install resource. owned Senpi row의 independent self-update는 막는다. standalone verified prefix만 별도 installation. --session full file; missing-create/fork/continue/last/picker/title 금지.
- recovery 화면은 target별 known effect/receipt/last identity/safe action을 보여준다. inspect는 무변경, reconcile은 기존 matching process/receipt를 adopt할 뿐 launcher/updater blind retry 없음. verified old/new restore는 별도 확인 operation, SIGKILL 금지.

- proposed inspect result: serverEpoch,paneGeneration,rootIncarnation:{pid,startIdentity,executableRealpath},session:{kind,fullId,storagePathHash},cwd,normalizedStartupOptions,turnGeneration,activeWork:{root,tools,subagents,monitors,continuations},inputSequence,resourcesFingerprint. Secret flag values는 core memory/private store의 reference만; token/secret argv 반환 금지.
- claim(expectedBinding,jobId,targetId,leaseOwner): atomic compare binding+generation와 work admission pause. 입력은 durable queue, claim 전에 admit된 모든 work를 완료 attestation 대상으로 포함. 반환 ownerToken/workGeneration/queueHead. 만료는 owner revoke와 recovery signal이지 자동 replay/side effect retry가 아니다.
- stop/start(operationId,ownerToken,expectedBinding): WAL intent+incarnation query와 compare action. target exited verified 이후 start, full session preflight+same cwd/options. result(operationId)는 absent/in-progress/completed/uncertain receipt 구분; uncertain이면 retry 안 함.
- release는 new exact identity와 integration input-consumed seq ack 후에만 queue drain. 새 prompt가 작업 시작하도록 replay할 때 actual consuming CLI ack가 없으면 자동 replay disabled+recovery.
- DB/API: Install{owner,channel,resources,installedVersion,lastCheck}; Runtime{socketEpoch,paneGeneration,rootIncarnation,session,cwd,optionsRef,runningVersion}; Job{requestId,mode,selectedTargets,installTxn,targetTxns,revision,status}; row CAS와 operationId. check는 spawn --version 등 bounded readonly probe만, update process는 별도 queue.
- 모든 mutations는 whole target binding을 fresh validate. UI stale selection을 server에서 거부하며 잘못된 process에는 SIGTERM도 보내지 않는다. shell과 whole workspace 종료/SIGKILL 금지.
- 정책 conflicting startup selector는 제거한 뒤 adapter exact resume selector를 추가한다. effective model/config/sandbox/permitted semantic options 보존. secret/unknown environment를 core가 secure reference로 보존 못하면 automatic resume disabled이며 completion로 표시하지 않는다.
