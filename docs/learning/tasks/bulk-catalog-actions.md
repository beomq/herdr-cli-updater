# 전체 최신 확인과 전체 업데이트

사용자 승인: 전체 조회, 새 버전이 있고 검증 가능한 설치만 일괄 검토 후 승인,
순차 업데이트, 항목별 결과, 세션 유지. 운영 CLI 업데이트와 재시작은 검증에서 제외한다.

## 구현

- `src/app/catalog-bulk.ts`: 전체 설치 카탈로그를 대상으로 조회한다. 한 항목의
  실패·미지원이 나머지 조회를 막지 않는다. 업데이트 준비는 조회와 기존 검증된
  계획 생성만 수행한다. 승인 전 설치·선택·버전·계획 revision을 재확인한다.
- 실행은 기존 `createCatalogUpdates.confirm`을 순서대로 호출하며 세션 정책은
  `keep`으로 고정한다. 실패·불확실은 그대로 남기고 재시도하지 않는다.
- 성공 후 기존 자동화의 관찰 버전을 갱신해 이 변경을 외부 업데이트로 오인하여
  나중에 세션을 재시작하지 않도록 한다. 자동화 활성 여부는 바꾸지 않는다.
- `catalog_bulk` SQLite 단일 행에 가장 최근 전체 작업을 저장한다. 브라우저
  새로고침은 작업을 재전송하지 않는다. 서비스가 중단되면 실행 중 항목은
  불확실, 미실행 항목은 건너뜀으로 남기고 자동 재개하지 않는다.
- `web/catalog-bulk.tsx`: 전체 확인·업데이트 준비, 항목별 버전·제외 이유,
  한 번의 승인, 진행 결과를 기존 UI 컴포넌트로 제공한다. 검색 필터와 독립이다.

## 범위와 한계

대상은 발견된 카탈로그 CLI별 선택 설치다. 미지원 설치나 같은 CLI의 다른
사본까지 무조건 업데이트하지 않는다. 화면의 최신 버전은 조회 시점 값이고,
기존 실행기는 실행 시점 공식 latest를 설치한 후 실제 버전을 검증한다.
패키지 관리자가 공유 잠금 파일을 변경하면 다음 항목의 기존 계획 검증이
거부될 수 있으며 새 검토가 필요하다. 검증을 무시하거나 재승인 없이 계획을
다시 만들지 않는다. 서비스 재시작 후 전체 작업 결과는 남지만 개별 조회
캐시는 기존과 같이 재조회가 필요하다.

## 검증

전체 앱·웹 테스트 472개 실행 통과 후 선택 대상 nullable 타입 오류를 수정했다.
수정 후 관련 66개 테스트, typecheck, build 모두 exit 0. 전체 확인의 무변경,
순차 실행, 한 항목 실패 후 다음 진행, 변경된 승인 거절, 재시작 후 재실행
금지, 세션 유지와 자동화 관찰 기준값을 검증했다.

후속 오류 안내 변경은 관련20개 테스트·타입·빌드 통과, 조회 실패 분리
추가 회귀는6개 테스트 통과. LSP 오류 없음. 격리 SQLite와 실제 일괄 모듈,
가짜 설치 실행기를 연결한 브라우저에서 1440px/390px 라이트·다크를 확인했다.
전체 조회 시 업데이트0건, 검토 취소 시 승인0건, 오래된 확인창 실행 비활성화,
최종 승인1건·keep 정책·완료 결과, 새로고침 후 승인 재전송0건을 확인했다.
가로 넘침 없음. 임시 화면 서버·브라우저·저장소는 정리했다.
Lighthouse 점수와 운영 배포는 이번 검증에 포함하지 않았다.

운영 서비스와 이 대화 터미널은 재시작하지 않았다. 구현은 소스·빌드에 있으며
운영 서버 반영은 별도다. 실제 전체 업데이트는 실행하지 않았다.

후속 운영 반영: 사용자의 `반영해줘` 승인으로 2026-10-13 앱 서비스만
정상 중지·재시작했다. PID71835에서53032로 교체했고 기존 포트62204와
브라우저 인증은 유지했다. 준비 상태 ready 확인. 대화 PID86154와 부모
셸65985의 시작 시각은 유지했다. 실제 CLI 업데이트는 실행하지 않았다.
실제 브라우저에서 서비스 연결됨, 설치 CLI9개, 전체 최신 확인·전체 업데이트
준비 버튼 표시를 확인했다. 기존 미확정 업데이트 기록2개는 그대로 보존했다.

## 직접 확인과 문제 확인 순서

운영 앱 반영 후 대시보드에서 `전체 최신 확인`으로 항목별 결과를 확인하고,
`전체 업데이트 준비`에서 버전·제외 이유를 검토한다. 취소하면 설치는 바뀌지
않는다. 실행 결과가 불확실하면 먼저 항목의 기술 상세, 업데이트 기록,
선택 설치 경로의 실제 버전 순서로 확인한다. 확인 없이 재실행하지 않는다.
