# CLI Updater

Herdr 없이 실행하는 로컬 CLI 관리 화면입니다. 첫 지원 대상은 **macOS의 Bun 전역 OmO 설치**입니다. 설치 버전과 관리 세션의 실행 버전을 따로 보여주고, 업데이트 준비·확인·실행 및 대화 보존 재시작을 제공합니다.

관리 지원 범위는 **OmO, Pi, OMP, OpenCode, Claude Code, Codex, GJC** 7종입니다.
나머지 herdr 세션은 **터미널 세션**에서만 `아직 지원하지 않음`으로 표시하며,
설치 관리·최신 조회·업데이트·자동 업데이트·재시작을 제공하지 않습니다.
기존 CLI 설치와 대화는 삭제하지 않습니다. 기존 미지원 CLI 자동화도 실행하지 않습니다.

지원 CLI는 **자동 업데이트 → 설치된 CLI 업데이트**에서 업데이트만 실행하거나
일정을 설정할 수 있습니다. 앱 전용 설치와 출처를 증명한 npm/Bun 전역 설치를
대상으로 하며, 이 경로는 세션을 종료하거나 재시작하지 않습니다.

## 설치와 실행

Bun 1.4.2 이상과 Node 24 이상이 필요합니다. 관리 대상 CLI의 전역 폴더와 분리된 전용 폴더에 설치합니다.

```sh
mkdir -p "$HOME/.local/share/cli-updater-app"
bun add --cwd "$HOME/.local/share/cli-updater-app" /absolute/path/herdr-cli-updater-0.1.0.tgz
export PATH="$HOME/.local/share/cli-updater-app/node_modules/.bin:$PATH"
cli-updater
```

브라우저가 열리고 로컬 서비스는 백그라운드에서 유지됩니다. 브라우저를 닫아도 진행 중인 작업이나 설정한 자동 확인은 취소되지 않습니다. 현재 npm 레지스트리에 게시한 패키지는 아니므로 위 명령에는 전달받은 파일의 실제 경로를 사용합니다.

`PATH` 설정을 셸 설정 파일에 유지하거나 전용 폴더의 `node_modules/.bin/cli-updater`를 직접 실행합니다. 앱 tarball을 OmO와 같은 Bun 전역 폴더에 설치하면 Bun이 업데이트 중 앱까지 다시 추출할 수 있어 원본 변경 범위 검증이 거부합니다.

```sh
cli-updater --no-open           # 브라우저 대신 접속 주소 출력
cli-updater status             # 로컬 서비스 상태
cli-updater stop               # 작업을 끊지 않는 정상 종료
cli-updater serve              # 포그라운드 실행
cli-updater --help
```

데이터 기본 경로는 `~/.local/share/cli-updater`입니다. 다른 경로는 `--state-dir /absolute/path`로 지정합니다. 웹 서버는 `127.0.0.1`에만 바인딩합니다. 처음 출력된 주소는 일회용 인증 주소입니다. 승인된 브라우저는 같은 주소와 상태 폴더에서 최대30일간 인증을 유지하며, 서비스 재시작만으로 만료되지 않습니다. 새 브라우저·기간 만료·다른 포트에서는 `cli-updater open`으로 새 접속 창을 엽니다.

## 동작 범위

- **설치**: 현재 설치된 OmO 버전과 최신 조회 결과를 표시합니다. 준비 단계에서는 원본 배포 자료와 격리 설치를 검증하고, 실행 확인 전에는 대상 OmO를 업데이트하지 않습니다.
- **관리 세션**: 이 서비스가 직접 실행한 OmO만 종료·재시작합니다. 작업과 승인이 진행 중이면 대기합니다. 원본 RPC의 안전한 해제 결과, 실제 프로세스 종료, 재실행 후 대화 식별자를 확인합니다.
- **외부 실행**: 현재 사용자의 OmO·OMP·Pi·Claude·Codex CLI를 실행 위치로 식별하고 터미널·시작 시각을 관측합니다. 15초마다 목록을 갱신하며 관측 실패는 마지막 성공 시각과 함께 표시합니다. 설치와 연결할 수 없거나 실행 버전을 증명할 수 없으면 미확인으로 남기고 제어하지 않습니다.
- **업데이트 기록**: 이 앱에서 설치 성공을 검증한 시각과 결과를 저장합니다. 실행 세션의 재시작 시각이나 다른 도구의 업데이트를 설치 성공 시각으로 추정하지 않습니다.
- **자동화**: CLI별 토글 하나로 켜고 끕니다. 켜면 즉시 공식 최신 버전을 확인하고, 이후 1시간마다 새 버전이 있을 때만 업데이트합니다. 설정·승인창은 없으며 업데이트 전후 버전과 결과를 내역에 표시합니다. 실행 중인 세션을 자동으로 종료하거나 재시작하지 않습니다.

설치 버전, 세션 실행 당시의 OmO 버전, 실제 엔진 버전은 서로 다른 값입니다. 업데이트해도 기존 프로세스의 버전을 새 버전으로 바꿔 표시하지 않습니다.

자세한 사용 순서와 복구 범위는 [USAGE.md](USAGE.md)에 있습니다.

## 개발과 패키지 생성

```sh
bun install --frozen-lockfile
bun test
bun run typecheck
bun run build
bun pm pack --destination dist
```

런타임 TypeScript와 웹 배포 파일을 함께 패키징합니다. 워커·준비 프로세스의 진입 경로가 이동 후에도 유지되도록 서버 전체를 하나의 번들로 합치지 않습니다. 기존 Herdr 플러그인 진입점은 `scripts/plugin.ts`에 별도로 유지합니다.
